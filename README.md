Keep PDF URLs stable and ensure `citation_pdf_url` points to the full PDF in the same directory. Update the sitemap when adding documents. Styles are embedded in each HTML file; `assets/` from the earlier local version is no longer used. GitHub Pages publishes `main` / repository root; no build tools are needed.
