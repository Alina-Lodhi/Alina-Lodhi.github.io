## Maintain this site

Edit `index.html` to update the biography, paper entries or course notes. Styles and favicon are embedded in the page. To add a document, upload its PDF alongside `index.html`, copy an article block, update its title, summary and both links, and update the document count. Replace the course section's empty state when course materials are available.

## GitHub Pages

Publish from the `main` branch and `/(root)` folder in Settings → Pages. No build tools or external dependencies are required.
